# Revisão do site D’artes Crochê

Atualizado em 17/11/2026. O site é uma vitrine com pedido de orçamento pelo WhatsApp; não há checkout.

## Conferido

- [x] Página inicial e página de políticas servidas pela Vercel.
- [x] Logo, ícone e fotos carregam por URLs públicas.
- [x] Título, descrição, imagem, URL canônica e idioma configurados para compartilhamento.
- [x] Galeria mostra fotos reais; a imagem do girassol tratada identifica a edição e oferece a foto original.
- [x] Formulário exige nome, peça e descrição; CEP e detalhes adicionais são opcionais.
- [x] Formulário monta a mensagem no navegador e abre o WhatsApp informado, sem gravar os dados no site.
- [x] Valores, frete, prazo e entrada são apresentados como informações a confirmar no orçamento, sem promessas inventadas.
- [x] Links internos, seção de trabalhos, perguntas frequentes e políticas acessíveis pelo HTML.
- [x] Animações leves usam opacidade e transformação; preferência por movimento reduzido é respeitada.
- [x] Imagens abaixo da primeira tela usam carregamento adiado; a imagem principal tem prioridade alta.

## Conferir com a proprietária antes de divulgar para vendas

- [ ] Formas de pagamento e valor ou percentual de entrada.
- [ ] Prazo típico de produção e opções reais de envio.
- [ ] Endereço físico e contato eletrônico para completar as informações do fornecedor.
- [ ] Revisão da decisão de não exibir CPF com orientação jurídica, pois a regra de comércio eletrônico prevê identificação do fornecedor.
- [ ] Autorização para usar as fotos e aprovação das legendas e da imagem tratada.

## Verificações externas pendentes
